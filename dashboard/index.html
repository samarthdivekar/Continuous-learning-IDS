How to use this console

This console watches network traffic as a graph — computers are dots, conversations between them are lines — and flags attacks. It keeps learning new attack types without forgetting old ones.

Where to start

  1. Take the tour — the ▶ button at the bottom of the sidebar walks you through the console in five steps.
  2. Overview — the results in one screen.
  3. Incident queue — what an analyst works through: incidents, why they were flagged, what to do.
  4. Live sites — the live view: replay a recorded attack, run the cyber range, or feed a sensor; then label and adapt.
  5. Stream replay — replays the recorded dataset through the models to show drift detection and self-updating.
  6. Graph explorer (under More) — see an attack as a shape: scans fan out, floods fan in.

The bar at the top sets the context for every page: the dataset (2017 / 2018), whether attacks are named (multiclass) or only attack/benign (binary), and Compare models, which adds every baseline next to the deployed model. Keys 1–9 switch pages, ? opens this panel and Ctrl+K opens the command palette: jump to any page, switch dataset, open an incident by number, or start and stop the stream.

Glossary

Flow
One network conversation between two computers, summarised by 83 numbers (duration, packets, bytes…).
Window
5,000 consecutive flows turned into one graph.
Task
A period in which a new kind of attack appears. The model learns tasks one after another.
Macro-F1
Detection quality averaged over every category, so rare attacks count as much as common ones. 1.0 is perfect.
Retention
Recall on the first attack type learned, after learning all the others. 1.0 = nothing forgotten.
False-positive rate
Share of normal traffic wrongly flagged. Every 0.1% is an alarm someone must dismiss.
Forgetting (BWT)
How much older tasks got worse after later training. Closer to 0 is better.
EWC
Protects the weights that mattered for old attacks while learning new ones.
Replay
Keeps a small sample of old traffic graphs and rehearses them during training.
Drift / ADWIN
Traffic changes over time. ADWIN watches the error rate and triggers an update when it shifts.
Incident
A group of alerts that belong together (same attacker or same victim), reviewed as one item.
Abstain
When the model is not sure enough it passes the flow to a human instead of guessing.
Dry run
Proposed firewall rules are shown and recorded, never applied.
